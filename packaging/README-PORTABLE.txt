Profile Isolator — Windows portable
===================================

中文
----
1. 解压本目录（或只使用 ProfileIsolator.exe）
2. 双击 ProfileIsolator.exe 运行
3. 需要 WebView2 运行时（Windows 11 一般已自带；Win10 可从微软安装）
4. 配置与 profile 不在本目录：默认在 %USERPROFILE%\CodexProfiles 与 ClaudeProfiles
   应用设置：%USERPROFILE%\.profile-isolator\

用途：为 Codex CLI / Claude Code 使用不同供应商时隔离配置，可多开并行。

English
-------
1. Unzip (or use ProfileIsolator.exe alone)
2. Run ProfileIsolator.exe
3. Requires WebView2 (usually preinstalled on Windows 11)
4. Profiles live under %USERPROFILE%\CodexProfiles and ClaudeProfiles by default
   App settings: %USERPROFILE%\.profile-isolator\

Source / releases: https://github.com/lottshin/profile-isolator
